# ベンチマーク概要とスペック対比 (Benchmarks Overview)

`sokuto` の実機ベンチマーク実測値サマリーと、
各検証領域(速度・精度/較正・異常検知・量子化)の詳細レポートへのポータルです。

> [!NOTE]
> 初期プロトタイプ (v0.2.1) では英語向け ModernBERT (149M) を使用していましたが、
> 日本語入力時に形態素分割が破綻し、
> 推論確率が完全な一様分布(Choice 各 33%、Noul 各 50%)に縮退する課題が発生しました。
> 日本語ネイティブの `sbintuitions/modernbert-ja-130m` へ換装したことによって
> 推論分布の縮退を解消・改善し ([PR #2](https://github.com/MI-1222/sokuto/pull/2))、
> 超低遅延(Choice 12.61ms)を達成しました。
> さらに複雑な業務判断・法的合意判定向けに `modernbert-ja-310m` を導入して
> Choice 精度 90% 超へと改善したことで ([PR #6](https://github.com/MI-1222/sokuto/pull/6))、
> 速度重視の Tier 1 と精度重視の Tier 2 という責務分離が確立されました。

## 2. 詳細ドキュメントへのリンク

各領域のハイライトと、詳細ドキュメントへのリンクです。
詳細な数理定義、検証データセット内訳、および再現手順はリンク先を参照してください。

### ① [推論レイテンシとスループット評価 (`latency-throughput.md`)](./latency-throughput.md)

CPU 上で **12.2ms 〜 23.3ms (p50)** の単一推論遅延を達成。クラウド商用 LLM(500ms〜数秒)と比較して **約 40 倍〜 100 倍高速** に確率決定を返します。

**主要成果**:

- メモリ再利用バッチ(Scratchpad)により、Tier 1 で **156.9 dec/s** の高スループットを記録。
- 物理コア数自動検出(`num_cpus::get_physical()`)により、ハイパースレッディング論理コア競合による性能劣化(-17.6%)を完全排除。
- 77 候補の大規模探索を 2 段階粗密探索(Coarse-to-Fine)により約 39ms で完了。

### ② [決定精度と確率較正評価 (`accuracy-calibration.md`)](./accuracy-calibration.md)

JGLUE ベンチマークで **Choice 精度 90.09%**、**Noul 正解率 97.50%** を達成しつつ、**ECE (期待較正誤差) 2.61%** という極めて高い信頼性を両立。

**主要成果**:

- 置換同変アテンション (SAB) により、選択肢の提示順序バイアスを幾何学的に中和(平均確率変動幅 **0.65%**)。
- 厳密適格スコアリング規則(RLCD)と正則化付き温度較正により、確信度 0.8 での実正解率が **82.4%〜85.2%** となる安心安全な確率を出力。
- 未学習・低精度ドメインにおいて温度最適化の暴走を防ぐ「精度ゲーティング安全弁」を実証。

### ③ [OOD (該当なし・未定義入力) 検知評価 (`ood-evaluation.md`)](./ood-evaluation.md)

業務外テキストや未定義カテゴリに対し、モデルが勝手に既存候補を選んでしまう過信(幻覚)を、ヘルムホルツ自由エネルギーに基づく安全弁回路で遮断。

**主要成果**:

- 実務 ID 13 件 vs OOD 13 件の実機テストにおいて、両 Tier ともに **OOD 検知率 92.3%** を達成。
- Tier 1 で **AUROC 97.63%** の高弁別能を記録。
- Tier 2 のロジット圧縮に対しては低温エネルギー温度($T=0.15$)と確信度・マージン複合ハイブリッド判定を導入し、System 2 (LLM) への確実なエスカレーションを実現。

### ④ [量子化パリティ評価 (`quantization-parity.md`)](./quantization-parity.md)

バックボーンのみを動的 INT8 化し、デシジョンヘッドを高精度 FP32 に保持する「選択的ハイブリッド動的 INT8 量子化」を採用。

**主要成果**:

- モデルサイズを最大 **55.62% 削減**(Tier 1: 278.4 MB / Tier 2: 537.5 MB)。常駐 RAM **< 350MB / < 750MB** を達成。
- FP32 ベースラインとの **Top-1 決定一致率 100.0%**、平均コサイン類似度 **0.999 超** を達成し、決定の狂いをゼロに抑制。

## 3. ベンチマークの再現

`sokuto-cli` を用いて、全シナリオの一括測定(JSON 出力)を即座に手元で実行できます。

```bash
# Tier 1 モデルの全シナリオ包括ベンチマーク (500 反復)
./target/release/sokuto benchmark \
  --model-dir models/quantized \
  --scenario all \
  --iterations 500 \
  --json > benchmark_results_tier1.json

# Tier 2 モデルの全シナリオ包括ベンチマーク (500 反復)
./target/release/sokuto benchmark \
  --model-dir models/modernbert-310m-int8 \
  --scenario all \
  --iterations 500 \
  --json > benchmark_results_tier2.json
```

> [!TIP]
> 個別シナリオ測定(single, batch, coarse, scratchpad)の引数や、
> Python 較正テスト・Rust 統合テストの実行手順は
> 各詳細ドキュメントを参照してください。
