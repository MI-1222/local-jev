# OOD (該当なし・未定義入力) 検知性能評価

分類モデルを実務に投入した際、最も危険な挙動は
**定義されていないカテゴリや完全な無関係テキストが入力された際に、既存の選択肢の中からどれか 1 つを勝手に高確信度で選んでしまう** ことです。

`sokuto` では、
統計力学のヘルムホルツ自由エネルギー(Free Energy)に基づく OOD 検知回路と、
確信度・マージン複合ハイブリッド安全弁を搭載し、
実機検証において
**両 Tier で OOD 検知率 92.3% (目標 90% 以上達成)** および **AUROC 97.63% (Tier 1)** を実現しています。

---

## 1. 自由エネルギー OOD 検知の数理定義

全ロジット $z = (z_1, \dots, z_K)$ の総和情報を保持するヘルムホルツ自由エネルギー $E(x; T)$
および候補数正規化自由エネルギー $E_{\text{norm}}(x; T)$ を用います。
(数理的参考ドキュメント: [`docs/architecture/gating.md`](../architecture/gating.md), [`docs/architecture/ood-safety.md`](../architecture/ood-safety.md))

$$E(x; T) = -T \cdot \ln \sum_{i=1}^{K} \exp\left(\frac{z_i}{T}\right)$$

### 候補数正規化自由エネルギー ($E_{\text{norm}}$)

単純な自由エネルギー $E(x; T)$ は候補数 $K$ が増加するだけで統計的に約 $-T \ln K$ だけ自然低下します。
`sokuto` ではタスクや階層ルーティングによって候補数 $K$ が動的に変動するため、
候補数の基底エネルギー偏向を補正した**正規化自由エネルギー**を採用し、単一の閾値判定を可能にしています。

$$E_{\text{norm}}(x; T) = E(x; T) + T \ln K = -T \cdot \ln\left( \frac{1}{K} \sum_{i=1}^K \exp\left(\frac{z_i}{T}\right) \right)$$

- **分布内(In-Distribution: ID)データ**:
  - いずれかの正解候補のロジット $z_k$ が大きく正に突き抜けるため、$E_{\text{norm}}$ は**負の値または小さな値**(低エネルギー)をとります。
- **分布外(Out-of-Distribution: OOD)データ**:
  - すべての候補のロジットが低調にとどまるため、$E_{\text{norm}}$ は**正の大きな値**(高エネルギー)をとります。
- **判定ルール**:
  - $E_{\text{norm}} > \tau_{\text{energy}}$ の場合、未定義入力(OOD)と判定して System 2 (LLM) へエスカレーション(Fallback 短絡)します。

## 3. Tier 1 vs Tier 2 OOD 性能対比 (実測サマリー)

上記 26 サンプルに対する実測ログの対比

| 評価指標                                        |       Tier 1 (130M-INT8)        |       Tier 2 (310M-INT8)        |    目標基準    |    判定    |
| :---------------------------------------------- | :-----------------------------: | :-----------------------------: | :------------: | :--------: |
| **AUROC (判別能面積)**                          |       **97.63%** (0.9763)       |       **80.47%** (0.8047)       |  $\ge 80.0\%$  |    合格    |
| **ID 平均エネルギー ($E_{\text{ID}}$)**         | 0.836 (Min: -1.230, Max: 3.485) | 0.617 (Min: -0.480, Max: 1.254) |       -        |     -      |
| **OOD 平均エネルギー ($E_{\text{OOD}}$)**       | 5.983 (Min: 1.952, Max: 10.537) | 1.242 (Min: 0.374, Max: 2.035)  |       -        |     -      |
| **エネルギー分離マージン ($\Delta E$)**         |            **5.147**            |            **0.625**            | $\Delta E > 0$ | 明確に分離 |
| **OOD 検知率 (TPR)**                            |    **92.3%** (12/13 件検知)     |    **92.3%** (12/13 件検知)     |  $\ge 90.0\%$  |  **合格**  |
| **ID 誤棄却率 (FPR)**                           |    **15.4%** (2/13 件誤棄却)    |    **23.1%** (3/13 件誤棄却)    |  $\le 25.0\%$  |    合格    |
| **安全弁方式**                                  |     単一自由エネルギー閾値      |     複合ハイブリッド安全弁      |       -        |     -      |
| **最適エネルギー温度 ($T_{\text{energy}}$)**    |              1.00               |        **0.15** (低温化)        |       -        |     -      |
| **推奨エネルギー閾値 ($\tau_{\text{energy}}$)** |            **2.50**             |      **1.00** (ハード閾値)      |       -        |     -      |

> [!NOTE]
> **背景コラム: Tier 2 INT8 におけるロジット圧縮の罠と複合ハイブリッド安全弁**
>
> Tier 1 ではロジットのダイナミックレンジが広く、エネルギー分離マージン $\Delta E = 5.147$、単一閾値 $\tau=2.5$ で AUROC 97.63% を達成しました。
> 一方、Tier 2 (310M) を INT8 量子化した際、重み丸め誤差により出力ロジットのダイナミックレンジが圧縮され、エネルギー分離マージンが $\Delta E = 0.625$ まで縮小し、標準温度 $T=1.0$ では単一閾値での完全分離が困難になりました。
> これを解決するため、ランタイムに以下の 2 段階の安全弁を導入しました。
>
> 1. **エネルギー温度の低温化 ($T_{\text{energy}} = 0.15$)**: 指数部を急峻化してロジット間のわずかな差を極大化。
> 2. **複合ハイブリッド安全弁**: 単一エネルギー判定 $E(x) > \tau_{\text{energy}}$ (1.00) に加え、緩和エネルギー $E(x) > \tau_{\text{loose}}$ (0.20) かつ不確実性(幾何確信度 $S_{\text{confidence}} < \tau_{\text{conf}}$ (0.40) または Top-Margin $M(p) < \tau_{\text{margin}}$ (0.20))の論理積・和判定を適用。
>
> この 2 段階の安全弁をランタイムに導入したことによって、
> Tier 2 でも目標を上回る **AUROC 80.47% / 検知率 92.3% (12/13 件)** へと回復・改善しました ([PR #6](https://github.com/MI-1222/sokuto/pull/6))。

- ポジティブ推薦: $E = -0.041$ (Tier 1) / $0.915$ (Tier 2) → **低エネルギー(自律承認)**
